# МАК — исследование себя

Версия 0.2. Прототип Telegram Mini App.

## Что уже работает в прототипе

- 7 тем исследования.
- Необязательный контекст перед началом.
- Случайный ассоциативный образ без заданного психологического значения.
- 36 реальных изображений карт из двух листов исходной колоды (2 страницы × 18 карт).
- Диалог из набора вопросов примерно на 15–22 шага.
- Итог: наблюдение, возможное противоречие, связь с контекстом и один вопрос для себя.
- Локальная история завершённых исследований через localStorage.
- Поделиться результатом через системное меню телефона или копирование текста.
- Поддержка Telegram WebApp API, если приложение открыто внутри Telegram.

## Важно

Это прототип без backend и без AI. Карты не имеют заранее заданных психологических значений; результат собирается из собственных ответов пользователя.

Следующий этап — подключить остальные листы колоды, затем backend и AI-модуль для более глубокого анализа ответов.
